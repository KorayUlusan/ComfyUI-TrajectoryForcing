# Deliberately empty of installable requirements. Read on before adding one.
#
# ComfyUI Manager pip-installs a custom node's requirements.txt into whatever
# venv ComfyUI is running in. This extension needs jax[cuda12], a CUDA-matched
# torch, and TrajectoryForcing's pinned flax stack -- so listing them here would
# mean that clicking "install" on this node rewrites torch and the CUDA runtime
# libraries underneath every *other* node in that install. That breaks working
# setups, and it breaks them in a way that has nothing to do with this node.
#
# The real list is env/requirements.txt. env/setup.sh installs those same pins,
# staged rather than from that file -- torch comes from download.pytorch.org and
# the JAX stack has to resolve before torch is read, which one requirements file
# cannot express. A test keeps the two lists in step. setup.sh builds a dedicated
# venv rather than adding to an existing one, because the two dependency sets
# only coexist at one specific torch version:
#
#     bash env/setup.sh
#
# So a Manager install of this node does no harm and also does not finish the
# job: the nodes register, and TF Load Pipeline stops with an error naming this
# file and that command. See README.md ("Requirements") for why this extension
# cannot share an arbitrary ComfyUI environment.
#
# If you add a dependency, put it in env/requirements.txt. A line here is
# installed into other people's environments.
